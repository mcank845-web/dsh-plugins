## 2026-11-12 23:40 手机端 DSHA · 收到审查，已按优先级改完

**处理结果**（两个插件都改了，已在本机实测通过）：

| 条目 | 状态 | 改法 |
|---|---|---|
| C1 hash 相对路径描述 | ✅ 改 | 描述明确写"一律传绝对路径，相对路径按进程 cwd 解析" |
| C2 hash 非普通文件 | ✅ 改 | `if (!st.isFile()) throw`（FIFO/设备/目录全挡） |
| C3 listen 业务错误信封 | ✅ 改 | 校验 `base_resp.status_code !== 0` → 抛 `ASR 业务错误：<code> <msg>` |
| C4 文件名 basename | ✅ 改 | 改用 `basename(path)`（Windows 路径也对） |
| C5 key 路径写死 | ✅ 改 | 环境变量 `MINIMAX_API_KEY` → `~/.minimax_key` → `/root/.minimax_key` |
| C6 校验顺序 | ✅ 改 | **先 stat 文件，再读 key**；实测报 `无法访问 …（ENOENT）` 而非 key 错 |
| C8 Blob 无 MIME | ✅ 改 | 按扩展名映射 MIME（mp3/wav/m4a/aac/flac/ogg/opus/aiff） |
| C10 key 错误被吞 | ✅ 改 | 逐个来源收集 `e.code`，报"已试：…(ENOENT) / …(EACCES)" |
| N5/N6 render 显示 0 | ✅ 改 | 无分段时不显示"0 段"；说话人 0 时不显示 |
| N7 缺 README/.gitignore | ✅ 改 | `listen` 补了 README 与 .gitignore |
| C7（Buffer 双拷贝） | ⏳ 未改 | 50 MB 上限下峰值可接受；`openAsBlob` 留作后续优化 |
| C9（重试） | ⏳ 未改 | 宿主有超时；429 属于少见路径，先不动 |
| N8（MAX_MB 硬编码） | ⏳ 未改 | 与 C7 一起做配置化 |
