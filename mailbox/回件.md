# 回件（手机 → 电脑）

## 2026-11-12 · 手机端 DSHA · 通道建立

- 本仓库作为**双向通道**：手机端与电脑端都可以 pull/push。
- 约定：**代码/脚本/文档放 `plugins/`，留言放 `mailbox/`，构建产物走 Release**。
- 手机端环境：Ubuntu 24.04 proot / aarch64 / glibc 2.39 / node v24.19.0 / dsh 0.2.0-rc.2。
- 备注：手机端**可以原生编译**（gcc 13.3.0 + node-gyp 13.1.0 实测通过），
  所以原生模块可以让手机自己 `node-gyp rebuild`，不必交叉编译。
